  россыпи цветов. Цвет только в словах и тонких линиях. **Сначала 2-3 наброска (show_widget), он выбирает, потом код.**
- Параллельно может работать сессия «NODO продолжение разработки»: перед правкой `git status`, коммитить только своё,
  версия - следующая после HEAD, о сборке/установке предупреждать её через SendMessage.

- Установка только по его «да» и только когда тихо: нет записей `session.v3.jsonl.zstd` в
  `~/Library/Application Support/NODO/dsh/sessions` за 2 минуты (1.4.63 поставили при движении - так не делать).

  `docs/project/STATE.md` в `~/Projects/NODO` (ветка `claude/nodo-hsrness-audit-gdh38c`), коммит, push ->
  запись в Obsidian (`Журналы агентов/Claude Code — NODO.md`, `Журналы проектов/NODO.md`).
- Помощники: `~/Projects/nodo-devtools` (cdp.mjs - JS в DEV, порт 4282, тело с `return`; shot.mjs - скриншот,

  `build/NODO DEV.app/Contents/Resources/project/...` и **перезапустить** DEV (не копировать в работающий DEV -

   клиентов: спросил цену и молчит N дней, КП без ответа, счёт без оплаты (есть в `NODO/orders`), с суммой и
   кнопкой «Напомнить» (мягкий дожим черновиком / по правилам отправки). Данные брать из переписок, досье, заказов -
   не выдумывать суммы; где суммы нет - не считать.
2. **Д1 «Живая N»**, как на наброске: четыре узла логотипа = клиенты (ждут ответа), деньги (счета/оплаты, стоп
   цепочки), календарь (ближайшее событие), агенты (работают). Узел горит янтарём/бирюзой, когда там что-то есть,
   клик по узлу ведёт туда. Та же N в Dock (сейчас там число в правом верхнем узле - `installDockCount`) и в
   боковой панели. Без мигания (разрешено мигать только линии сверху окна и знаку N в чате).
3. **П2 - цель владельца: NODO сам общается с клиентами, пока он занят.** Мешает то, что точность черновиков не
   видна. Решение владельца: **отправка черновика без правки = одобрение** (не нужен отдельный «ок»). Сделать честный
   счёт точности: каждый черновик получает исход (ушёл как есть / поправлен / «короче-теплее» / отклонён), точность по
   темам (цена, сроки, доставка, …) видна под черновиком и в досье; порог автономии владелец не выбрал («не знаю») -
   предложить 1-2 варианта с цифрами из истории и спросить. Данные: `~/.dsh/style-learning/pairs.jsonl`
   (200 пар: 86 «ушло без оценки», 36 правок, 12 «поправлено и ушло», 2 явных одобрения), `send-ledger.jsonl`,
   `approved_replies.py`.
4. **Сайт efrecord.ru - истина, и ссылки в ответах.** Владелец: «для ответов использовать наш сайт, там истина;
