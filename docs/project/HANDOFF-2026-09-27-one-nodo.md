## Что работает
- **Пульс** `~/.dsh/bin/nodo-pulse` (launchd `com.nodo.pulse`, 5 мин): сводка `NODO/pulse/efrecord.md`, срезы
  `NODO/clients/pulse/<чат>.md` - кто, УЖЕ БЫЛО С КЛИЕНТОМ, заказы (NODO/orders), календарь, неподтверждённое, дела,
  касания/«позже», заметки, последние реплики + «НЕ здороваться», для своих - «Люди проекта». Сам синхронизирует
  allowed-chats (чаты с клиентской сессией - по «да» владельца).
- **Конвейер** `~/.dsh/bin/nodo-draft` - единственный писатель черновика клиенту (Telegram-мост 1.4.84 и WhatsApp-мост
  `~/.dsh/whatsapp/wa-bridge.py`). Контекст кодом, вся пачка неотвеченных, переписывание неотправленного черновика,
  проверки кодом (приветствие, обещания, «уже отправил», пустое «Запускаю?», ты/вы с повтором, личные/группы).
  need -> сессия ищет факты -> `nodo-draft --chat N --facts "…"`. Черновик в `~/.dsh/drafts/<чат>.json`, «отправляй» =
  этот текст (правило в AGENTS NODO). Ошибка конвейера -> старый путь (агент + коуч). Лог `~/.dsh/drafts/drafts.jsonl`.
- Коуч `~/.dsh/bin/nodo-coach`: пульс в контексте, не-клиенты `~/.dsh/sales-coach/not-clients.json` (свои, соискатель,
  поставщик SubStore, мама Валеля - личное), страховки кодом, маршрут сети запоминается (`route.txt`, 2-4 с).
- Правила NODO `NODO/dsh/AGENTS.md` 43 КБ + ситуационные `NODO/dsh/rules/*.md`.
