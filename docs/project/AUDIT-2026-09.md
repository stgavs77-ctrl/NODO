# Аудит NODO 1.4.0 (2026-09-24)

Статический аудит кода в четыре параллельных прохода: ядро и задачи, контекст и провайдеры, безопасность
и Remote, сборка, обновления и тесты. Ключевые находки перепроверены по коду. Номера строк относятся
к коммиту `881d0da`. Отметки: ✅ исправлено (этап 0), ⏸ отложено владельцем.

## Сильные стороны
- Окна Electron: `contextIsolation`, `sandbox`, `nodeIntegration:false`. IPC проверяет отправителя и URL.
- Медиа и вложения: realpath, проход без symlink, `O_NOFOLLOW`, лимиты размера.
- Команды запускаются через `execFile`/`spawn` с массивом аргументов, `shell:true` нигде нет.
- Обновления: манифест подписан Ed25519, проверяется sha256, есть откат кода и Rescue.
- Remote: одноразовое сопряжение, AES-GCM с AAD, защита от повторов через `seq` и challenge.

## 2. Безопасность (⏸ отложено)
- CDP-порт открыт всегда (`main.cjs:41`). Тестовый HTTP-сервер в production (`main.cjs:91`).
- Remote доверяет JS, который отдаёт relay. Сквозное шифрование защищает только от пассивного relay (`remote-web/client.js`, `lib/remote-host.cjs:49`).
- Токен DSH пишется в `dsh.log` (`main.cjs:108,142`). `DEEPSEEK_API_KEY` в env DSH и его инструментов (`main.cjs:140`); нужно проверить, видит ли его bash.
- Codex хранит OAuth в файле (`codex-config.toml:2`). Ключ вспомогательной модели в открытом `auxiliary.json` и отправляется на любой URL (`lib/auxiliary.cjs:57,78,153`).
- Блокировка loopback во встроенном браузере обходится (`lib/browser.cjs:6`). GitHub-токен уходит при редиректе на чужой хост (`lib/github.cjs:19`).
- Telegram: код вне репозитория, текст сообщения виден в `ps`, возможна prompt-инъекция (`lib/telegram.cjs:12,33,40`).
- Вспомогательная модель получает сырой текст, допускается `http://` (`interpreter-runtime.cjs:94`, `interpreter.cjs:341/398`).
- Обновления: один ключ без ротации (`config/release-trust.json`), ключ можно передать через env (`scripts/release.cjs:49`), подпись ad-hoc без нотаризации.
- `remote-host.enable()` не проверяет `webURL` (`lib/remote-host.cjs:17,21`). У `remote-web` нет CSP. Ключи устройств не истекают.

## 4. DeepSeek, контекст и деньги
- Цены только для одной модели, `cost()` не принимает модель (`cost-meter.cjs:6-22,65-67`). Старые записи считаются по текущему тарифу, из-за этого тесты падают в пиковые часы.

- ✅ `recencyOf(item,intent)` вместо `newest` (`context-engine.cjs:98`).
- Фильтр `score>0` никогда не отсекает документы (`:104-107`). В Economy пустой шаг `past-sessions`. Размер «до» оценивается грубо (`:226`).
- Reference-блок, возможно, заново добавляется на каждом шаге (`project-runtime.cjs:120-135`); нужно проверить.

- Баланс: только эндпоинт DeepSeek, даже если выбран другой провайдер (`balance.cjs:12`). Keychain опрашивается каждую минуту.
