## Правило работы с владельцем
Владелец не программист. Не проси его запускать команды, собирать проект или смотреть код. Всё, что
проверяется автоматически, проверяй сам: CI на Mac, GitHub MCP. К владельцу обращайся только за
решениями («что делать»), а не за действиями («как сделать»).
